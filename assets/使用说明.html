DockClickMin 使用说明

点 Dock 图标收起前台应用 · 版本 1.0.8 · macOS 13+ · MIT

这是一个菜单栏常驻的小工具：点 Dock 上当前前台应用的图标，把它收起来；再点一次还原。相当于 Windows 任务栏的行为，macOS 原生没有这个开关。

默认最小化优先，动画跟随系统设置。QQ 使用自身的最小化菜单 / ⌘M，再点图标由 Dock 原生恢复；隐藏模式和部分兜底操作没有动画。

1拖进「应用程序」

打开 DockClickMin-1.0.8.dmg，把 DockClickMin.app 拖到旁边的 Applications 快捷方式。

2首次打开时放行

本应用没有 Apple 开发者签名，第一次打开会被系统拦下。按下面这条路径放行：

⚠︎
双击被拦 → 点「完成」→ 打开 系统设置 › 隐私与安全性 › 安全性 → 点「仍要打开」→ 输密码 → 再点「打开」

注意：macOS 15 Sequoia 起，「右键 → 打开」这条老办法已被 Apple 移除，弹窗里不会再有「打开」按钮，只能走上面这条路径。

3授权辅助功能

启动后会弹「DockClickMin 想要控制这台电脑」，点「打开系统设置」，在 隐私与安全性 › 辅助功能 里打开 DockClickMin 的开关。

授权后 不用重启：程序每 2 秒复查一次权限，最多 2 秒自动开始工作。菜单栏出现 dock 图标、菜单里状态显示「监听中 · N 个图标」即成功。

菜单说明

项作用
启用总开关，关掉后不再监听
开机自启默认开启，登录时自动运行
唤出时提到最前默认开启。点 Dock 图标唤出应用后，把它的主窗口提到最前；QQ 等原生命令兼容应用除外
收起方式：最小化优先（不兼容时隐藏）默认。使用系统最小化动画；QQ 只用自身菜单 / ⌘M，普通应用失败时可回退到隐藏
收起方式：隐藏整个应用（瞬时，无动画）等同 ⌘H，瞬间消失
状态：监听中 · N 个图标实时确认是否正常
打开日志出问题时可看，路径 ~/Library/Logs/DockClickMin.log

使用边界

操作结果

常见问题

点了没反应？

先看菜单里状态是不是「监听中」。若是「未授权」或「已授权，未监听」，去 隐私与安全性 › 辅助功能 里把 DockClickMin 的开关关掉再打开。

个别应用（如 Clash Verge 这类没有「隐藏」菜单的 app）可能无法隐藏，工具会依次尝试多种方式，最后降级为最小化；日志里能看到每一步的结果。

为什么有些应用会「闪一下」？

部分应用收到隐藏请求后会自己弹回来，看起来像闪一下。工具会等待并检查实际隐藏状态，结果写进日志。

可以切回默认的「最小化优先」方式；原生最小化命令支持系统动画，属性兜底和隐藏没有动画。

开机自启在哪里关？

菜单栏图标 → 取消勾选「开机自启」即可，同时会删除 ~/Library/LaunchAgents/com.geekaudio.DockClickMin.plist。

如何完全卸载？ 
launchctl bootout gui/$(id -u)/com.geekaudio.DockClickMin 2>/dev/null
rm -f ~/Library/LaunchAgents/com.geekaudio.DockClickMin.plist
rm -rf /Applications/DockClickMin.app ~/Library/Logs/DockClickMin.log
defaults delete com.geekaudio.DockClickMin 2>/dev/null
Dock 自动隐藏时反应慢一点？

图标位置每秒刷新一次，Dock 刚探出来时可能还来不及更新，约 1 秒内点击可能无效。Dock 常驻显示时没有这个问题。

技术说明

本工具不注入、不修改系统文件，只用系统公开 API：读取程序坞的辅助功能树得到图标位置，监听鼠标按下/抬起，再执行收起。普通点击原样放行；只有关闭已打开的启动台时，会吞掉那一次点击，避免关掉后又被 Dock 打开。
